# Factorsets

Versioned, content-addressed emission-factor data. Layout: `<source>/<vintage>/` holding
`manifest.toml` (publisher, vintage, license, method notes, checksum) and `factors.parquet`.

## Licensing and redistribution

Record per source whether it may be redistributed. Some sources (Clean Cargo, IATA CO2
Connect, ecoinvent) are not freely redistributable: commit only open data here and load
customer-licensed data from outside the repository.
